# Project 22: Hospital Management System (Aegis Health)

A React + Vite + TailwindCSS + Zustand demo application for managing day-to-day hospital workflows.

## Modules
- Patient registration, inpatient registry, patient search, admission and discharge
- Patient medical records with diagnosis, attending doctor, and recorded medical-history entries
- Doctor consultation scheduling
- Prescription record entry and prescription history
- Ward and bed occupancy tracking
- Medical and nursing staff duty roster
- Itemized billing and payment status tracking
- Hospital occupancy and operational analytics

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Notes
This is a frontend demonstration with sample data held in Zustand application state. It does not include a production database, authentication, or a live hospital integration. Replace the sample records and connect a secure backend before using it with real patient information. Prescription entries are for recording clinician-provided instructions; this application does not generate medical advice.
